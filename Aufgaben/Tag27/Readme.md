
# Individual Learning Phase – Hybrid Identities and Connectivity in Azure

## Übersicht
Im Rahmen dieser Aufgabe wurde eine hybride Azure-Umgebung geplant und dokumentiert. Dabei wurden hybride Identitäten, die Synchronisation zwischen Active Directory und Microsoft Entra ID sowie eine Site-to-Site-VPN-Verbindung konzipiert.

## Bearbeitete Aufgaben

### ✅ Task 1 – Hybrid-Architektur
- Eine Hybrid-Architektur mit On-Premises Active Directory und Microsoft Entra ID erstellt.
- Azure Virtual Network, Azure VPN Gateway und eine Azure-VM integriert.
- Identitäts- und Netzwerkverbindungen dargestellt.

### ✅ Task 2 – Azure Portal
- Die Verwaltungsbereiche für Microsoft Entra ID, Virtual Networks, VPN Gateways und Resource Groups im Azure-Portal identifiziert.
- Tenant, Subscription und Region dokumentiert.

### ✅ Task 3 – Synchronisationsplanung
- Synchronisationsumfang für verschiedene OUs festgelegt.
- Benutzer, Gruppen und Geräte für die Synchronisation ausgewählt.
- Microsoft Entra Connect Sync als Synchronisationslösung eingeplant.

### ✅ Task 4 – Benutzer-Workflow
- Den vollständigen Ablauf von der Erstellung eines Benutzers im lokalen Active Directory bis zur Anmeldung an einem Cloud-Dienst beschrieben.
- Synchronisation und Authentifizierung klar voneinander abgegrenzt.

### ✅ Task 5 – Site-to-Site VPN
- Eine vollständige VPN-Konfiguration geplant.
- Netzwerke, Gateways, Adressbereiche und Verbindungseinstellungen definiert.

## Erweiterungsaufgaben

### Extension Task 1
- Microsoft Entra Connect Sync und Cloud Sync verglichen.
- Cloud Sync für eine Umgebung mit ca. 150 Benutzern empfohlen.

### Extension Task 2
- Checklisten für typische Fehler erstellt:
  - Benutzer wird nicht synchronisiert.
  - Cloud-Anmeldung schlägt fehl.
  - VPN-Verbindung kann nicht aufgebaut werden.

## Verwendete Technologien

- Microsoft Azure
- Microsoft Entra ID
- Active Directory Domain Services
- Microsoft Entra Connect Sync
- Azure Virtual Network (VNet)
- Azure VPN Gateway
- Site-to-Site VPN

## Fazit

Alle Aufgaben der Individual Learning Phase wurden erfolgreich bearbeitet. Dabei wurde eine vollständige hybride Zielarchitektur entworfen, eine Synchronisationsstrategie zwischen Active Directory und Microsoft Entra ID geplant sowie eine Site-to-Site-VPN-Konfiguration vorbereitet. Dadurch wurde ein grundlegendes Verständnis für hybride Identitäten und hybride Netzwerkanbindungen in Microsoft Azure aufgebaut.
